# Roshani Foods Website

A responsive HTML/CSS/JS restaurant website based on the supplied reference image.

## Files
- index.html — page structure/content
- styles.css — responsive design + animations
- script.js — smooth scrolling + fade-up IntersectionObserver

## Important replacements
1. Replace the sample food/interior image URLs in `index.html` with Roshani Foods' real photos.
2. Replace the placeholder phone, WhatsApp, email and address.
3. Replace the Google Maps URL in the "Open in Google Maps" button with the actual Roshani Foods Google Maps URL.
4. For an embedded interactive map, replace `.map-placeholder` with the iframe code from Google Maps:
   Google Maps > Search your business > Share > Embed a map > Copy HTML.

The normal Google Maps share URL is best used as a clickable link. A true embedded interactive map normally uses Google's Embed option / Maps Embed API.
